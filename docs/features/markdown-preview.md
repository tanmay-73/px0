# Markdown Preview

Markdown files (`.md`, `.markdown`) open in the editor like any other file. The preview is a separate tab, as in VS Code:

- **Markdown: Open Preview** (`Ctrl/Cmd+Shift+V`) opens it in the current group.
- **Markdown: Open Preview to the Side** (`Ctrl/Cmd+K V`, or the preview button in the editor title bar) opens it beside the source.
- **Open Preview** is also on the explorer's and the tab's context menu.

The preview tab is titled `Preview <file>` and is restored with the other tabs on reload. It refreshes when the file is saved.

---

## What it renders

- **GitHub Flavored Markdown**: tables, task lists, strikethrough, autolinks and footnotes, with GitHub's heading IDs so tables of contents work.
- **GitHub alerts**: `[!NOTE]`, `[!TIP]`, `[!IMPORTANT]`, `[!WARNING]` and `[!CAUTION]` blockquotes become styled callouts.
- **Code blocks** are syntax-highlighted on the server, show their language, and have a copy button.
- **Mermaid diagrams**: fenced `mermaid` blocks render as diagrams in the theme's colours, with zoom, fit and full-screen controls; an invalid diagram leaves its source visible with the error. The Mermaid runtime is fetched once on first use and cached under `~/.px0/cache/vendor/` (or `$XDG_CACHE_HOME/px0/vendor/`).
- **Raw HTML** in the file (centred logos, `<details>`) is kept, after sanitizing.
- **Images**: relative images load from the workspace; web images load as usual. Images load lazily.

## Links

- A link to a heading in the same file scrolls the preview.
- A link to another Markdown file in the workspace opens its preview; a link to any other workspace file opens it in the editor.
- Web links open in a new browser tab. `Ctrl/Cmd`-click a workspace link to open the raw file in a new browser tab.

## Safety

A Markdown file is untrusted input. Everything the server renders is rebuilt in the browser against an allowlist before it reaches the page: scripts, styles, frames, forms, SVG and event handlers are removed, `javascript:` and other schemes are dropped, and no element keeps a `style` attribute. Only diagrams generated by the pinned, strict-mode Mermaid runtime add SVG. See [Markdown Preview Internals](../internals/markdown.md#4-sanitization).

## Limits

- Files over 4 MB are not previewed. The preview commands also appear on `.mdx` files, but the server renders only `.md` and `.markdown`, so an `.mdx` preview shows an error.
- Fences over 256 KB and fences without a language are not highlighted.
- The preview follows the saved file, not unsaved edits, and does not scroll with the editor.

## Keys

| Key | Action |
| :--- | :--- |
| `Ctrl/Cmd+Shift+V` | Markdown: Open Preview |
| `Ctrl/Cmd+K V` | Markdown: Open Preview to the Side |
| `Esc` | Leave a full-screen Mermaid diagram |

For the goldmark pipeline, heading IDs, the sanitizer and Mermaid, see [Markdown Preview Internals](../internals/markdown.md).
